# 试题二：课表解析与空闲时段计算

一个从课表算空闲时间的小工具。三个需求分三次提交（对应三个 PR），
最后补了一次真实数据的实例报告。

- ✅ **需求 1** 读入课表（手动录入 / CSV），打印「本周课表」文本视图
- ✅ **需求 2** 算空闲时段（合并同一课程连续节次，不出现碎片）
- ✅ **需求 3** 找多人的共同空闲时间（按空闲长度降序）

## 快速开始

不需要任何第三方依赖，Python 3.8+ 直接用标准库跑：

```bash
git clone https://github.com/wyh66649/hiahia.git
cd hiahia

# 打印本周课表
python main.py show --csv data/student_a.csv

# 换成周视图表格
python main.py show --csv data/student_a.csv --view grid

# 算空闲时段
python main.py free --csv data/student_a.csv --day-start 08:00 --day-end 22:00

# 找两个人的共同空闲时段
python main.py common --csv data/student_a.csv --csv data/student_b.csv

# 手动录课
python main.py manual
```

## 需求 1：读入课表

### 标准格式

字段就是需求里说的四个（`地点` 可选）：

```csv
课程名,星期几,开始时间,结束时间,地点
高等数学,周一,09:00,09:45,致理楼A302
高等数学,周一,09:55,10:40,致理楼A302
大学英语,周一,14:00,15:40,文科楼B105
```

表头写得很随意也能读：

- 列的顺序随便排，**列名中英文都认**（`课程` / `course` / `name` …）
- 没有表头时，按 `课程名,星期几,开始时间,结束时间[,地点]` 的顺序读
- `星期几` 支持 `周一` / `星期一` / `礼拜一` / `1` / `Mon` / `Monday`
- 时间支持 `09:00` / `9:00` / `9：00`（全角冒号）/ `0900` / `9`
- 以 `#` 开头的行当注释跳过
- 某一行写坏了只跳过那一行并提示行号，不会整个文件读不进来
  （`load_csv(..., strict=True)` 可改成直接报错）

### 教务系统导出的原始课表（网格格式）

教务系统导出的 CSV 是一整张网格表（第一列节次、后面每列一天、一个格子里塞好几门课），
工具能自动识别，**不需要先手工转换**：

```bash
python main.py show --csv data/同学A课表.csv
python main.py show --csv data/同学A课表.csv --view grid
```

也可以把原始课表转成标准格式，方便自己再编辑：

```bash
python main.py convert data/同学A课表.csv -o my_timetable.csv
python main.py convert data/同学A课表.csv --with-meta   # 多导出「教师 / 周次」两列
```

解析时会顺手处理这些脏活：

- 自动识别文件编码（教务导出的多是 **GBK**，手写的 CSV 多是 UTF-8，都不用管）
- 一个格子里写了多门课 → 拆成多条
- 同一门课的不同周次写成多行（`3周 王老师…` / `6周 李老师…`）→ 并成一条，周次 / 教师拼起来
- 课程名尾部的课程编号（`工科数学分析Ⅰ 07`）自动去掉
- 页脚的「打印人 / 打印时间」不会被当成课程
- 表头里的姓名、学号、学年学期自动提取出来
- 名字的优先级：**命令行 `--owner` > 课表里印着的姓名 > 文件名**
  （文件名会顺手去掉 `课表` / `_raw` 之类后缀，`同学A课表.csv` 就显示成「同学A」）

### 手动录入

```bash
python main.py manual
```

一问一答，课程名直接回车结束。填错了（`25:00`、`第八天`）会被追问而不是崩掉。

### 文本视图

`--view day`（默认）：按天列表，带每门课的时间和地点。

```
本周课表 · 张三
====================================================

【周一】3 门次，合计 3 小时 10 分
  09:00-09:45  高等数学  @致理楼A302
  09:55-10:40  高等数学  @致理楼A302
  14:00-15:40  大学英语  @文科楼B105
...
----------------------------------------------------
共 7 门次，分布在 5 天。
```

`--view grid`：周视图表格，行是时间段、列是星期。

## 需求 2：算空闲时段

给定每天的可用时间范围，算出每天的空闲时段：

```bash
python main.py free --csv data/student_a.csv --day-start 08:00 --day-end 22:00
python main.py free --csv data/student_a.csv --day 周一        # 只看某一天
python main.py free --csv data/student_a.csv --min-minutes 60  # 只留一小时以上的
```

输出：

```
student_a 的空闲时段（每日可用 08:00 - 22:00）
====================================================

【周一】3 段空闲，合计 10 小时 40 分
  08:00-09:00    1 小时
  10:40-14:00    3 小时 20 分
  15:40-22:00    6 小时 20 分
...
```

### 「同一课程连续两节」是怎么合并的

大学里两节连上中间休息 10 分钟很常见，导出成 CSV 就是两条记录：

```csv
高等数学,周一,09:00,09:45
高等数学,周一,09:55,10:40
```

不处理的话，算空闲时会得到「09:00-09:45 有课 → 09:45-09:55 空闲 → 09:55-10:40 有课」，
凭空多出一个只有 10 分钟、根本没法用的碎片空闲。

`timetable.slots.merge_courses` 会把**同一门课 + 同一天 + 间隔不超过 `--gap`（默认 15 分钟）**
的相邻节次并成一块 `09:00-10:40`，碎片就没了。可以直接对比：

```bash
python main.py free --csv data/student_a.csv --day 周一            # 合并后：3 段
python main.py free --csv data/student_a.csv --day 周一 --no-merge # 多出一个 09:45-09:55
```

注意只合并**同名课程**：09:00-10:00 的高数和 10:00-11:00 的英语是两门课，不会被揉成一条。

`show --view day/grid` 默认也走合并后的视图，加 `--no-merge` 可以看每一节的原始排布。

## 需求 3：找共同空闲时间

把多个人的课表一起丢进来，算出**所有人都空着**的时段：

```bash
python main.py common --csv data/同学A课表.csv --csv data/同学B课表.csv
python main.py common --csv 我.csv --csv 室友.csv --csv 组长.csv --top 5   # 只看最长的 5 段
```

`--csv` 想写几个写几个。结果按空闲时长**降序**排列。

### 真实案例：同学A + 同学B

`data/` 里那两份就是真实课表（姓名学号已抹掉）。两人是同一个班组的，
课表高度重合，唯一区别是周二「国际象棋」的时间 —— A 是 19:45-21:15，B 是 18:00-19:30。

```
共同空闲时段 · 2 人（同学A、同学B）
每日可用 08:00 - 22:00，按空闲时长降序
========================================================
   1. 周六 08:00-22:00      14 小时
   2. 周四 10:30-15:45      5 小时 15 分
   3. 周一 17:15-22:00      4 小时 45 分
   4. 周四 17:15-22:00      4 小时 45 分
   5. 周五 17:15-22:00      4 小时 45 分
   6. 周日 17:15-22:00      4 小时 45 分
   7. 周一 10:30-14:00      3 小时 30 分
   ...
--------------------------------------------------------
共 25 段可共同安排的时间。
```

完整排名 + 两人的每周课表对照见 **[`docs/共同空闲时段.md`](docs/共同空闲时段.md)**。
那份文档是脚本生成的，换了课表重跑一下就能刷新：

```bash
python tools/make_common_report.py                    # 写回 docs/共同空闲时段.md
python tools/make_common_report.py --min-minutes 60   # 只把够用的时段写进结论
```

> 这 25 段里有 6 段不到 1 小时，其中 5 段只有 15 分钟 —— 那是两节课之间的课间休息，
> 名义上空着但根本没法约。加 `--min-minutes 60` 过滤后就只剩 19 段，才是真正能用的清单。

### 为什么不能把所有人的课「摞在一起」再算空闲

因为「共同空闲」的语义是 *所有人都空着*，不是 *没有人上课*。

如果先把三个人的课表合并成一张，再算空闲，那么「甲有课、乙没课」的时间也会被算成占用，
结果会**偏小**，把本来能约的时段漏掉。所以流程是：

1. 每个人各自算每日空闲（复用需求 2 的合并逻辑）；
2. 逐天对所有空闲列表取**交集**（双指针，O(n+m)）；
3. 汇总后按「越长越靠前」排序，长度相同按星期、开始时间排，保证输出稳定。

`--min-minutes` 可以过滤掉太短的片段，`--gap` / `--no-merge` 会一路透传到每个人自己的空闲计算里。

## 设计与实现要点

- **时间一律用「从 00:00 起的分钟数」（int）表示**，只在输入输出时转成 `"HH:MM"`。
  这样比较、算长度、求交集都是整数运算，不会踩 `"9:00" > "10:00"` 这种字符串字典序的坑。
- **时间段用半开区间 `[start, end)` 而不是闭区间**。
  `09:00-10:00` 和 `10:00-11:00` 是首尾相接而非重叠 —— 这一点直接决定了空闲时段会不会
  凭空多出或漏掉一分钟。
- 模型层的 `Course` 保持「一节一条」，**要不要合并连续节次是上层的事**，
  模型不为某个展示需求做妥协。
- 终端里中文是双宽字符，`display` 自己算显示宽度来对齐表格，不会错位。
